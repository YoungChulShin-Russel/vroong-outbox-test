# 📘 Outbox 공통 모듈 구축 작업 계획서

## 1️⃣ 프로젝트 개요
**목표**
- MSA 환경에서 각 서비스가 일관된 방식으로 Kafka 이벤트를 발행할 수 있도록 Outbox 패턴을 공통화한다.  
- Spring Boot 2.x(기존 서비스)와 4.x(신규 서비스) 모두에서 호환 가능한 구조로 제공한다.  
- 코드 중복을 줄이고, 서비스별 유지보수 부담을 최소화한다.

---

## 2️⃣ 아키텍처 개요

### 🔹 전체 구조
```
outbox-core/
 ├─ OutboxEvent.java
 ├─ OutboxRepository.java
 ├─ KafkaPublisher.java
 ├─ JsonSerializer.java
 └─ OutboxProcessor.java

outbox-spring-2x/
 ├─ javax.persistence.* 기반 Entity/Repository
 └─ Spring KafkaTemplate 연동 Adapter

outbox-spring-4x/
 ├─ jakarta.persistence.* 기반 Entity/Repository
 └─ Spring KafkaTemplate 연동 Adapter
```

### 🔹 역할 분리
| 모듈 | 역할 |
|------|------|
| **outbox-core** | 순수 Java 기반 핵심 로직. DB insert, event 직렬화, publish queue, retry 관리 등 |
| **outbox-spring-2x** | Spring Boot 2.x 호환. `javax.persistence.*` 기반 JPA + Spring Kafka 연동 |
| **outbox-spring-4x** | Spring Boot 4.x 호환. `jakarta.persistence.*` 기반 JPA + Spring Kafka 연동 |

---

## 3️⃣ 주요 컴포넌트 정의

| 컴포넌트 | 설명 |
|-----------|------|
| **OutboxEvent** | Outbox 테이블에 저장될 이벤트 엔티티. ID, aggregateId, payload, createdAt, status 포함 |
| **OutboxRepository** | DB에 Outbox 이벤트를 저장 / 조회 / 상태 변경하는 인터페이스 |
| **KafkaPublisher** | Kafka로 이벤트를 발행하는 역할 |
| **OutboxProcessor** | 발행 대기 중인 이벤트를 주기적으로 조회 → Kafka 발행 → 성공 시 상태 갱신 |
| **JsonSerializer** | 이벤트 객체를 JSON 문자열로 직렬화 / 역직렬화 |

---

## 4️⃣ 데이터베이스 스키마 예시

```sql
CREATE TABLE outbox_event (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  aggregate_id VARCHAR(64) NOT NULL,
  type VARCHAR(128) NOT NULL,
  payload JSON NOT NULL,
  status VARCHAR(20) DEFAULT 'PENDING',
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  published_at DATETIME NULL
);
```

## 7️⃣ Outbox 발행 동작 흐름

```text
[비즈니스 트랜잭션]
   ↓
비즈니스 데이터 저장
   ↓
OutboxEvent Insert (같은 트랜잭션)
   ↓
[Outbox Processor (Scheduler)]
   ↓
OutboxEvent 상태가 PENDING인 이벤트 조회
   ↓
KafkaPublisher 통해 이벤트 발행
   ↓
성공 시 상태 → PUBLISHED 로 변경
```

## 🔟 향후 확장 계획

- Dead Letter Queue(DLQ) 지원  
- Outbox Event Archiver (오래된 이벤트 정리)  
- Observability (메트릭, 발행 성공률, 지연 시간 등)  
- Avro / JSON Schema 기반 Payload Validation  
- Transactional Event Publisher 추상화 (event sourcing 확장)
